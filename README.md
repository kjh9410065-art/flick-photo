# FLiCK Photo

TCFLiCK의 브라우저 전용 이미지 편집기. 이미지 파일을 전송하는 API, 외부 스크립트, 원격 폰트, 런타임 의존성이 없습니다.

## 실행

Node.js 24 이상에서 `npm start` 후 http://127.0.0.1:4173 을 엽니다. `npm run check`로 JavaScript 구문을 검사합니다. 안내 페이지 변경 후 `node scripts/docs.mjs`를 실행합니다. 빌드 없이 `dist`를 그대로 배포합니다.

## 운영 주소

- https://photo.tcflick.com/
- https://flick-photo.pages.dev/
- https://github.com/kjh9410065-art/flick-photo

Cloudflare Pages에 GitHub main 자동 배포를 연결했습니다. 공식 도메인의 SSL 활성 및 변환·다운로드를 검증했습니다. 상세 범위는 VERIFICATION.md를 확인하세요.

## Studio 2.0

홈페이지와 편집 화면을 별도 상태로 전면 재구성했습니다. PC에서는 도구 레일·중앙 캔버스·검사 패널·썸네일 목록을, 640px 이하에서는 하단 도구 레일과 접이식 설정 패널을 제공합니다.

- 형식·품질·픽셀/비율 크기·자르기·회전·반전은 이미지별 설정입니다.
- 최근 50개 설정 이력을 이미지별로 실행 취소/다시 실행할 수 있습니다. Blob을 이력마다 복제하지 않습니다.
- 최대 1400px 미리보기와 실제 출력 인코딩은 같은 engine.js 변환 파이프라인을 사용합니다. 미리보기 용량을 실제 파일 용량으로 표시하지 않습니다.
- 원본 비교 슬라이더, 확대·축소, 화면 맞춤은 실제 캔버스 표시를 변경합니다.
- 일괄 처리 도구는 선택한 이미지에 출력 설정만 복사하며, 자르기·회전·반전은 각 사진 설정을 유지합니다.
- ZIP에는 선택된 사진의 완료된 결과만 들어갑니다. 생성 후 ZIP 저장 링크를 누릅니다.
- 자르기 편집 중 내보내면 유효한 현재 영역을 반영합니다.
- 데모는 로컬에 포함된 AI 생성 이미지를 실제 편집기로 불러옵니다. ASSETS.md에 생성 도구와 프롬프트를 기록했습니다.

RENEWAL-VERIFICATION.md에 리뉴얼 검증 범위를 기록합니다.

## 처리 규칙

JPG/PNG/WebP만 입력. 파일당 30 MiB, 합계 120 MiB, 최대 20장, 이미지당 최대 40 MP. 출력 각 변 최대 12000px 및 40 MP. 한 장씩 처리하고 결과 Blob을 메모리에 보관합니다. 기기별 메모리 제한으로 더 작은 작업도 실패할 수 있습니다. ZIP은 UTF-8 파일 이름과 CRC32를 사용하는 무압축 ZIP입니다. 결과 파일명에 순번을 붙입니다.

자르기 → 회전 → 회전된 축에서 반전 → 크기 조절 → 인코딩. JPG 투명 영역은 흰색. PNG에는 품질값이 적용되지 않습니다. 브라우저 인코더에 따라 화질·색상·메타데이터가 바뀔 수 있습니다. 애니메이션은 보존하지 않습니다. 크기 감소를 보장하지 않습니다.

## 광고

`.ad-slot`은 광고가 없으면 hidden 상태입니다. 현재 광고 코드를 탑재하지 않았습니다. 실제 AdSense 게시자·슬롯 ID와 승인, 동의 관리가 확보된 뒤 별도로 도입해야 합니다. 광고 도입 시 개인정보 문서와 CSP를 갱신하고 `data-ad-status="unfilled"` 광고를 숨기는 처리를 적용해야 합니다. 허위 ads.txt는 만들지 않습니다.

## 개인정보

이미지와 이름은 DOM·Blob 메모리에만 있습니다. `connect-src 'none'`으로 앱의 네트워크 전송도 제한합니다. 정적 호스트 접속 로그는 호스팅 사업자 정책을 따릅니다. 원본은 수정하지 않습니다.

## Studio 3.0 편집 확장

다크 Studio를 유지하며 색상 6종·필터 7종·선명/흐림·텍스트/로고·영역 모자이크/흐림·배경/여백/테두리/원형·가로/세로 콜라주·소셜 규격·일괄 파일명을 추가했습니다. 모든 편집 상태는 이미지별 실행 취소 이력에 포함됩니다. 콜라주는 새 이미지로 추가되며 생성 자체는 원본의 설정 이력이 아닙니다.

공통 파이프라인은 자르기 → 회전/반전 → 크기 → 흐림 → 색상/필터 → 선명도 → 프레임 → 영역 → 레이어 → 출력 인코딩입니다. 미리보기는 같은 렌더러를 최대 1400px로 사용합니다. 출력 형식은 실제 브라우저 인코더로 검사해 지원되는 항목만 노출합니다. 기본 출력 40 MP, 고급 효과 16 MP, 결과 Blob 합계 120 MiB, 로고 합계 40 MiB로 제한합니다. 입력은 메모리 Blob으로 복사해 원본 파일의 외부 변경에 영향을 받지 않도록 합니다.

모바일은 하단 그룹 도구 모음과 접이식 패널을 사용하며 레이어/영역/자르기 모두 Pointer Events로 조작합니다. 색상 보정은 일반 RGB 처리이며 RAW·전문 색관리 기능은 아닙니다. 상세 검증은 ADVANCED-VERIFICATION.md를 확인하세요.

## Studio 3.1 사용 흐름 개선

기존 편집 엔진과 다크 디자인을 유지했습니다. ‘이미지로 시작하기’는 다중 파일 선택, ‘편집 시작하기’·‘스튜디오 열기’는 빈 스튜디오 또는 기존 작업으로 이동, ‘샘플 이미지 체험’은 별도 샘플 항목을 추가합니다. 홈페이지 16개 도구 카드가 도구별 패널로 바로 연결되며 빈 상태에서도 도구 선택을 보존합니다.

기존 데모 이미지를 엔진으로 실제 보정해 홈페이지 비교 슬라이더에 사용합니다. 키보드·Pointer Events 비교, 업로드 패널 전체 클릭/키보드, 업로드 진행·오류 안내, 실제 UI에 기반한 3단계 안내, FAQ, 가독성을 개선했습니다. 좁은 화면에서 파일 추가·홈 복귀를 유지하고, 높이가 짧은 창에서는 설정 패널 전체 스크롤을 제공합니다. 상세 검증은 UI-VERIFICATION.md를 참고하세요.
